# mceck-skills

Mattia Cecchini's agent skills for real engineering: grilling, spec and task flows, TDD, code review, domain modelling and more.

## Install

```bash
/plugin install mceck-skills --marketplace mceck/skills
```

## What is inside

- **Skills**: `init-workflow`, `write-spec`, `write-task`, `implement`, `tdd`, `task-review`, `write-docs`, `domain-modeling`, `grilling`, `grill-me`, `monade-manutenzione`.

## Local development

Link the skills into your local harness directories with `scripts/link-skills.sh`, and check the plugin with:

```bash
claude plugin validate .
```
